# DMAM PRO Hub

Hub personnel et professionnel d'Adonaï MOUZITA : projets, interventions,
conseils, notes et contact.

## Développement

Prérequis : Node.js 22 et Bun.

```bash
bun install
bun run dev
```

## Vérification

```bash
bun run typecheck
bun run lint
bun run build
```

Le projet est autonome et préparé pour un déploiement sur Netlify. La configuration de production se
trouve dans `netlify.toml`.
