# Agent Protocol

## Avant d'agir

1. Lire `AGENTS.md`, `PRODUCT.md`, `DESIGN.md` et ces piliers.
2. Vérifier l'état Git et ne pas écraser les changements non liés.
3. Choisir une preuve de réussite mesurable avant toute modification.
4. Utiliser le skill applicable et lire ses instructions complètes.

## Anti-boucle PUA

Après deux échecs similaires :

1. arrêter les ajustements de paramètres ;
2. lire le message complet et 50 lignes de contexte ;
3. vérifier chemin, version, permissions et dépendances ;
4. formuler trois hypothèses réellement différentes ;
5. changer d'outil ou de couche ;
6. vérifier la nouvelle approche avec un critère explicite ;
7. consigner le résultat dans `LESSONS.md`.

## Definition of Done

- Typecheck réussi.
- Lint sans erreur.
- Build de production réussi.
- Contrôle responsive à 1536, 864, 390 et 320 px.
- Liens et actions vérifiés.
- Détecteur Impeccable exécuté une seule fois en fin de passe UI.
- Commit poussé et workflow GitHub vert.
- Production Netlify HTTP 200.
